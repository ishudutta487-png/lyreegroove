# lyreegroove
A music-lyric web page



 a responsive, multi-page web application designed to celebrate our favorite music artists while providing an engaging experience for fans. Built entirely from scratch using clean HTML, CSS, and vanilla JavaScript, this front-end project serves as a beautifully styled hub for album discoveries and music discovery.
The platform splits into two primary experiences: a visual home dashboard highlighting artist biography timelines and album artwork galleries, and an interactive lyric-sync engine. Instead of cluttering the screen with text, the application utilizes dynamic JavaScript click events to swap out track lyrics smoothly inside a dedicated viewport, ensuring a sleek, uncluttered presentation.
